# GYBS — Get Your Brand Seen

This is the clean starting frontend for the GYBS advertising marketplace.

## Included
- GYBS landing page
- Uploaded GYBS logo
- Uploaded AI & Apps visual
- Uploaded Crypto visual
- Business and Website category cards
- Responsive mobile navigation
- Free 1–3 day demo messaging
- Advertiser submission form UI
- Client-side form validation
- No signup flow

## Important
The form currently displays a confirmation message only. It does NOT collect or store advertiser submissions yet.

The next development stage should connect:
1. A database for campaigns.
2. Secure ad-image uploads.
3. Your private admin dashboard.
4. Campaign approval/rejection.
5. Demo start/end dates and automatic expiry.
6. Crypto wallet address + QR payment page.
7. Transaction-hash submission and payment verification.
8. Automatic paid campaign activation.

## Files
- `index.html` — page structure
- `styles.css` — design and responsive layout
- `script.js` — menu, category selection and form behavior
- `assets/` — supplied GYBS images

## Free hosting later
This frontend can be deployed to a free static host. We can connect the repository to a free hosting service after the design is finalized.

## Security note
When the backend is added, never put private wallet keys, admin credentials, or other secrets inside frontend JavaScript.
